# Contributing to env-parser

## Local setup

```
git clone https://github.com/kmagesh197-cloud/env-parser
cd env-parser
cp .env.example .env
npm test
```

## Code conventions

- Two-space indentation, semicolons, single quotes.
- `parseEnv` must stay dependency-free and synchronous.

## Submitting changes

Open a PR against `main` with a short description and the fixture you added.
